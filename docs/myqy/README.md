## 约定

- 本 fork 新增的一切项目规则、约定与决策都放本目录，并在 `AGENTS.md` 末尾的
  `myqy-fork-rules` 声明块中登记（新增文件时同步更新上面的表格）。
- **多步计划必须落库**：凡是需要多批次/多步骤推进的计划，写入 [`plan/`](./plan/)（一份计划
  一个文件），开题时登记，执行进度与结论在该文件内更新，不要只留在聊天里。
- 本目录内容属于本 fork 自有，合并上游更新时不要被上游版本覆盖。
- 本目录下的文件同样受 `AGENTS.md`「隐私与本地环境信息」条款约束：不得写入本机路径、
  用户名、机器名、域名或凭据。
- **回复时间格式（2026-10-17 用户要求）**：AI 每次回复的第一行必须是当前时间，格式
  `yyyy年MM月dd日HH:mm:ss`（例：2026年10月17日03:09:28），不带其他前后缀。
- **对比上游用本地克隆**：对比上游作者最新代码与本 fork 分支时，基于仓库根 `上游作者项目/`
  的完整克隆，规则见 [`git-rules.md`](./git-rules.md) §6。
