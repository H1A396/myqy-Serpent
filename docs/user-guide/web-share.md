# 网页分享

把当前打开的一个资源库以**只读**方式分享给朋友，让他们在浏览器里浏览、搜索和预览，不需要安装 Serpent。

## 适用场景

- 用 frp（如樱花 frp）等隧道工具，把本机端口映射到一个公网地址，发给朋友。
- 朋友只需一个浏览器和一个分享密码，就能浏览文件夹、合集、标签，搜索和预览图片 / 视频 / 音频，并查看资产的描述、评分与标签。

网页端始终是只读的：访客不能导入、删除、改名或修改任何元数据。

## 开启步骤

1. 打开 **设置 → 网页分享**。
2. 在「分享密码」里设置一个至少 8 位的密码。没有密码时无法启用分享。
3. 打开「启用网页分享」开关，服务随即在 `127.0.0.1` 上启动；页面会显示本地地址和当前在线会话数。
4. 用隧道客户端把该本地地址映射到公网域名，例如把 `127.0.0.1:47890` 映射出去。
5. 把公网地址发给朋友，他们打开后输入分享密码即可浏览。

## 设置项

| 设置 | 说明 |
| --- | --- |
| 分享密码 | 访客进入时的口令。修改密码会让已登录的访客退出。 |
| 分享的资源库 | 只分享当前打开的一个资源库；默认取第一个打开的资源库。 |
| 允许下载原图 | 关闭后访客只能在线查看，不能下载源文件。 |
| 端口 | 服务在本机 `127.0.0.1` 上监听的端口，隧道客户端需映射同一端口。 |

## 安全说明

- 服务只绑定本机回环地址，不会直接暴露到局域网；对外访问完全由你选择的隧道控制。
- 请务必设置密码：公网地址可能被扫描到。
- 关闭开关或退出 Serpent，服务立即停止。
- 网页端不能修改资源库；分享密码只用于浏览，不是账号系统。

## 限制

- 浏览器无法解码的格式（如部分 RAW、3D、字体、HTML、EXR 等）只能下载后本地查看。
- 视频能否直接播放取决于浏览器对该编码的支持；不支持时同样只能下载。
- 一个分享只对应一个资源库。
