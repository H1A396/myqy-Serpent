# 网页分享

把当前打开的一个资源库分享给朋友：他们在浏览器里浏览、搜索、预览，并可标记自己的喜欢与评分；不需要安装 Serpent，也不会改动你的资源库。

## 适用场景

- 用 frp（如樱花 frp）等隧道工具，把本机端口映射到一个公网地址，发给朋友。
- 朋友打开链接后输入一个用户名即可进入（写什么都可以）：浏览文件夹、合集、标签，搜索和预览图片 / 视频 / 音频，查看描述，并可下载。

## 访客标记

- 每位访客可以给任意资产设置「喜欢」和自己的 1–5 星评分（点第几颗就是几星）。
- 这些标记只保存在**本机**的访客记录里、按访客分开，**不会修改资源库**——库主自己的评分与喜欢不受影响。
- 访客只能写自己的标记；导入、删除、改名、修改元数据在网页端一律不可用。

## 访客记录（后台）

在 **设置 → 网页分享 → 访客记录** 可以看到每位访客的用户名、IP、User-Agent、进入次数、首次/最近时间，以及喜欢/评分了哪些图，并可导出为 **JSON / CSV**。记录只存在本机。

## 缩略图（网页分享专用）

网格里的缩略图是**为网页分享单独生成**的一套小图，只影响访客看到的网格，**不改变软件本体**的缩略图。

- **分辨率**：128px / 256px（默认 128px）。两档都会缓存，这个设置只决定访客看到哪一档。
- **锐化**：默认开启。降采样后做一次轻度锐化，让边缘更清晰（否则 128px 会偏糊）。
- **自动生成**：导入新图时，如果它属于**当前被分享的那个库**，会自动生成两档缩略图。
- **重新生成（保底）**：设置页的「重新生成缩略图」按钮会按当前分辨率补齐缺失的缩略图；已有且未过期的会跳过，并顺手清理已删除/已替换图片的残留。
- 格式统一为 WebP；文件存在库内 `.serpent/share-thumbnails/`，随库一起删除，**不包含在库导出（Serpent ZIP）里**。

## 开启步骤

1. 打开 **设置 → 网页分享**。
2. （可选）设置「访问密码」。留空则不设密码，访客只需输入用户名。
3. 打开「启用网页分享」开关，服务随即在 `127.0.0.1` 上启动；页面会显示本地地址和当前在线会话数。
4. 用隧道客户端把该本地地址映射到公网域名，例如把 `127.0.0.1:47890` 映射出去。
5. 把公网地址发给朋友，他们输入一个用户名（如设了密码再输入密码）即可浏览。

## 设置项

| 设置 | 说明 |
| --- | --- |
| 访问密码（可选） | 留空则只需用户名。设置后访客需同时输入密码；修改密码会让已登录访客退出。 |
| 分享的资源库 | 只分享当前打开的一个资源库；默认取第一个打开的资源库。 |
| 允许下载原图 | 关闭后访客只能在线查看，不能下载源文件。 |
| 缩略图分辨率 | 访客网格缩略图的最长边，128px / 256px。 |
| 锐化缩略图 | 是否对缩略图做轻度锐化（默认开）。 |
| 重新生成缩略图 | 按当前分辨率补齐缺失的分享缩略图（保底）。 |
| 端口 | 服务在本机 `127.0.0.1` 上监听的端口，隧道客户端需映射同一端口。 |
| 访客记录 | 查看与导出访客的标记和访问信息。 |

## 安全与隐私

- 服务只绑定本机回环地址，对外访问完全由你选择的隧道控制。
- **不设密码时，任何拿到公网地址的人都能进入**；公网地址可能被扫描到，建议保持地址私密，或设置访问密码。
- 访客记录包含 IP、User-Agent 等个人信息，仅保存在本机；请合法、合规使用。
- 关闭开关或退出 Serpent，服务立即停止。

## 限制

- 网页端不能导入、删除、改名或修改资源库中的任何内容；访客只能写自己的喜欢/评分。
- 浏览器无法解码的格式（如部分 RAW、3D、字体、HTML、EXR 等）只能下载后本地查看。
- 视频能否直接播放取决于浏览器对该编码的支持；不支持时同样只能下载。
- 一个分享只对应一个资源库。
